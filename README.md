# HareRevengeRemake

This is a remake of a short game I made in college using DirectX.  The remake has been done using the Godot engine.  I used this game to learn how to make a game with the Godot engine.  Hopefully there will be more to come in the future. :)

# Basic story

This is a game based on what happened after the tortoise beats the hare.  Our hare (Harry) decides to get revenge on our tortoise (Sheldon) by stealing his lucky beanie.  It's up to Sheldon to retrieve his hat from Harry hefore the rematch.

# Controls

Use the arrow keys to move Sheldon.  
Press the down arrow key to have Sheldon hide in his shell.  While hiding, Sheldon cannot be hurt by anything.
Press the space bar to shoot a quick water blast that will damage enemies.
